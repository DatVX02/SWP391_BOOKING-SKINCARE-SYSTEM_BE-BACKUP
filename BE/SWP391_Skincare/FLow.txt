- Luồng chạy login + register: 
+ Đăng ký tài khoản -> gửi mã OTP về mail -> verify OTP -> login vào hệ thống

API test:
- Register: 
+ API: http://localhost:5000/api/auth/register
+ JSON:
{
  "username": "testuser",
  "email": "vxdat13@gmail.com",
  "password": "password123",
  "role": "user"
}
-> result: 
{
    "msg": "Mã OTP đã được gửi đến email. Vui lòng xác thực!",
    "email": "vxdat13@gmail.com"
}

- Verify-OTP: 
+ API: http://localhost:5000/api/auth/verify-otp
+ Json: 
{
  "email": "vxdat13@gmail.com",
  "otp": "799218" //OTP hệ thống trả về xem trong mongo
}
-> result: 
{
    "msg": "Xác thực thành công, bạn có thể đăng nhập!"
}
